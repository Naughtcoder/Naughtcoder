# Projects

Two iPhone apps I built, both local-first and built on Expo and React Native.

## [Household Expense Tracker](https://github.com/Naughtcoder/household-expense-tracker)
Tracks spending for a household. It reads bank texts and emails, files each payment into categories, splits shared costs, and shows budgets, trips and tax. Next.js website with a Supabase backend, plus a native iPhone app.

## [Healthy Me](https://github.com/Naughtcoder/healthy-me)
Follows a structured eating plan: meals, water, weight and supplements, with a meal builder, voice and photo logging, Siri, widgets and Apple Health.

Both repositories use invented demo data only.
